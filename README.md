# CapyPlay Celular

App da CapyPlay para celular e tablet Android.

## Baixar

**[Baixar CapyPlayCelular.apk](https://github.com/capyplayapp-web/capyplay-mobile/releases/latest/download/CapyPlayCelular.apk)**

Esse link sempre entrega a versão mais nova.

## Instalar

1. Abra o link acima no navegador do celular.
2. Quando o download terminar, toque no arquivo e em **Instalar**.
3. Se o celular pedir, permita que o navegador instale apps.

## Entrar

Abra o CapyPlay e digite o **usuário** e a **senha** da sua assinatura.

Precisa de Android 5.0 ou mais novo. iPhone não é compatível.

Para TV Box, Google TV e Fire TV, use o [CapyPlay TV](https://github.com/capyplayapp-web/capyplay-tv) (código **2473963** no Downloader).
